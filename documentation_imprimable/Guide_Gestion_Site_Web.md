# 📘 Guide Administrateur - Gérer le site avec Sanity

Ce document explique comment modifier le contenu du site (Textes, Produits, Prix de livraison) sans toucher au code.

---

## 1. Accéder à l'interface d'administration (Le Studio)

Le "Studio Sanity" est votre tableau de bord.

1.  Ouvrez votre navigateur.
2.  Allez à l'adresse : **[kti.badie.eu/studio](https://kti.badie.eu/studio)**
3.  Cliquez sur **"Log in with Google"**.

---

## 2. Modifier les Frais de Port

C'est ici que vous réglez les tarifs Colissimo et Point Relais.

1.  Dans la colonne de gauche, cliquez sur **"Paramètres du Site"**.
2.  Cliquez sur l'élément qui apparaît dans la liste.
3.  Dans la fenêtre centrale, choisissez l'onglet **Livraison**.
4.  Modifiez les champs selon vos besoins :
    *   Frais de Port : Domicile (Colissimo)
    *   Frais de Port : Point Relais
    *   Seuil de Livraison Offerte (Mettre 0 pour désactiver)

---

## 3. Ajouter ou Modifier un Produit

1.  Dans la colonne de gauche, cliquez sur **"Produits"**.
2.  **Pour modifier :** Cliquez sur un produit dans la liste.
3.  **Pour ajouter :** Cliquez sur le bouton **Create** (icône crayon) en haut à gauche.
4.  Remplissez les champs (Nom, Slug, Images, Prix, Description...).

### 3.B. Gérer les produits vendus (Sur Commande)

K'ti propose des pièces uniques. Quand un sac est vendu mais peut être refait :

1.  **Stock :** Mettez le stock à **0**.
2.  **Statut :** Cochez la case **"Sur Commande"**.
3.  **Options de personnalisation :** Écrivez un petit texte pour le client (ex: *"Ce modèle est vendu, mais je peux le refaire sur commande..."*).
4.  **Publier :** Cliquez sur le bouton vert "Publish".

---

### 3.C. Galerie Photo Avancée (Vues et Angles)

Pour préciser l'angle de chaque photo :

1.  Chargez vos photos dans "Photos du produit".
2.  Double-cliquez sur l'image ou cliquez sur le bouton **Edit** (crayon).
3.  Dans le menu **"Vue / Angle"**, choisissez l'option (Face Avant, Dessus, Détail...).
4.  Fermez la petite fenêtre.

---

## ⚠️ 4. Étape Cruciale : PUBLIER

*   Tant que vous ne cliquez pas sur le bouton vert **"Publish"** (en bas), les modifications ne sont **PAS** visibles sur le site internet.
*   Si le bouton est vert vif, c'est qu'il y a des changements en attente.

---

## 👥 5. Inviter quelqu'un à modifier le site

La gestion des accès au Studio se fait sur le site central de Sanity.

1.  Allez sur **[sanity.io/manage](https://www.sanity.io/manage)**.
2.  Connectez-vous.
3.  Cliquez sur le projet **"Kti"** > **"Members"**.
4.  **Inviter :** "Add member" (Rôle : Editor).
5.  **Supprimer :** "Remove from project".

---

## 🆘 En cas de problème

*   **Je ne vois pas mes changements sur le site :** Avez-vous cliqué sur "Publish" ? Avez-vous rafraîchi la page du site ?
*   **Le Studio ne charge pas :** Vérifiez votre connexion internet.
